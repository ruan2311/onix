Chave do GitHub

O anúncio fica no site do Project Gems. Para publicar daqui, o app precisa de uma chave do GitHub com permissão só para o repositório do site. Ela fica guardada só neste celular.

  1. Toque em Criar chave (abre o GitHub no navegador).
  2. Em Resource owner, escolha projectgems.
  3. Em Repository access, escolha Only select repositories → projectgems.github.io.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Toque em Generate token, copie a chave e cole aqui embaixo.
